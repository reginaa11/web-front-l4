## О проекте

Приложение для управления списком задач с сохранением в `localStorage`,
поиском, редактированием, удалением и отметкой о выполнении.

Реализовано в двух версиях:
- **Sass-версия** (ветка `lab-4`) — модульный SCSS, БЭМ, светлая/тёмная тема
- **Tailwind-версия** (ветка `lab-4-tailwind`) — утилитарные классы, сборка через npm

Обе версии доступны с клавиатуры и проверены на соответствие WCAG AA (Lighthouse ≥ 90).

## Установка и запуск

### Требования
- Node.js LTS с [nodejs.org](https://nodejs.org)
- npm (устанавливается с Node.js)
